# Chat projects

Zach wants the ChatGPT/Claude project concept: conversations sharing uploaded files and custom instructions. This extends the approved clean sidebar with Projects above Recents. The common Chat heading/collapse placement is retained.

Each project has a stable ID, name, instructions, and stored file snapshots. Clicking its folder expands/collapses conversations inline. Recents remains below the project list and contains unassigned conversations. The shared right-click menu offers Open project for the full page with instructions, files and conversations. Search includes nested project chats and temporarily reveals matching results. Project context is shown in the chat header, without repeating a project badge inside message bubbles; stored context snapshots remain intact. Existing conversations can be moved through their context menu; new conversations created in the project inherit it. Removing a project preserves its chats and clears their project association. Project membership is separate from the older example Notes/Tasks project labels.

The native ChatStore owns project persistence, validates references and accepts older stores without projects. Project instructions and source files are applied to each new request in the project, alongside that conversation's history. Files are quoted reference material; instructions are explicit user-authored configuration. Other conversations are not automatically shared as memory. Current project context is used after a move or edit, and each submitted message retains its own project-context snapshot for provenance. Public snapshots omit full file bodies/image payloads. Model vision support is checked for project images before saving or sending the message.

This first implementation passes project context directly; it does not implement retrieval or a vector database. Existing import formats apply: images, extracted PDF text, UTF-8 text/code. Limits: 10 files per project, 100 KB extracted text, 16 KB instructions; combined project and per-message text must fit the existing 100 KB context allowance. Larger knowledge collections and cross-chat memory are later work. Data remains local to the Mac until shared storage is implemented.

Attachment trigger rotates its existing plus icon by 45 degrees over 180 ms while the shadcn Popover is open, producing an X. It reverses when dismissed or an attachment action is selected. Reduced motion removes the transition while retaining the state change.

Reference behavior: https://help.openai.com/en/articles/10169521-projects-in-chatgpt and https://support.claude.com/en/articles/9519177-how-can-i-create-and-manage-projects (reviewed September 8, 2026).

Appearance changes persist immediately and propagate to the sidebar, project heading, and chat breadcrumb. Rename edits only the name; Settings edits name and instructions. Delete retains the existing confirmation and preserves conversations. Project conversation rows reuse the chat context menu; project files expose Preview and Remove from project.
