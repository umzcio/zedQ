# GitHub checks Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement these steps.

**Goal:** Run the existing tests and TypeScript checks on every push and pull request.
**Architecture:** One macOS job uses the committed npm lockfile, with pinned actions and no application credentials. Native integration probes remain separately gated.
**Tech Stack:** GitHub Actions, Node 26.5.0, npm 11.17.0.
**Spec:** User authorization: implement GitHub CI first, then native runtime recovery/boundary work.

## Global Constraints

- Use an isolated Git worktree and disposable test data.
- No signing keys, provider credentials, or normal workspace data in CI.
